# P6 · 家长一页说明（v5）

> 这页只回答四件事：怎么配置、审核到哪一步、数据存在哪、换设备怎么办。

## 1. 怎么配置
- **选年级**：工作台顶部「选择年级」1~6 年级。切年级会重建今天的任务，今天的完成记录清空，积分、连续天数和兑换记录保留。
- **配置单元（目前只作用于数学）**：工作台「课程设置」里选教材版本、册次、当前单元。配好后，数学只抽「当前单元 + 之前已学单元」的教材题；不配置就用全年级题池。
- **其他三科**：语文、英语、科学的 48 册内容已建好，但暂时按年级题池供给，还没有接到「当前单元」收敛开关。
- **每天题量**：由年级和星期决定，每项 4 道；不要为了多练去改这个数，改了会破坏去重与复习节奏。

## 2. 审核到哪一步
- 48 册新内容全部是 `pending-review`（待审核），**尚未上线**：已审核 = 0，线上生效 = 0。
- 四批审核批次：数学 `p2-math-batch-1`、语文 `p3-chinese-batch-1`、英语 `p4-english-batch-1`、科学 `p5-science-batch-1`。
- 家长核对面板目前只列 v4 遗留的 8 道 `ma-u01-c3-01~08`；48 册规格题还没有逐题 UI。逐册代表题、8 道遗留题与签字栏合并在 `docs/P6-汇总签字清单.md`，一份文档签字一次。
- **签字只代表抽样通过**，教材措辞和年级适配仍要审核人自己判断；签字后也不立即生效，要等明确说「放行」。

## 3. 数据在哪
- 只存在**本机浏览器**的 localStorage：键名 `user_<孩子名>_dailyTaskData`；每个孩子一个键，互不影响。
- 题目文本在源码分包里，不写进 localStorage；localStorage 只存做题记录、去重签名、掌握度、复习队列等。
- 备份入口：工作台 →「数据管理」→「导出 JSON」，下载 `每日任务备份-<用户>-<日期>.json`。
- 恢复入口：同一位置「导入 JSON」，会**覆盖**当前用户数据，导入前建议先导出当前备份。

## 4. 换设备怎么办
- **换设备 / 换浏览器不会自动同步**：先在两台设备上都导出，再把旧设备的备份在新设备上导入。
- **清理浏览器缓存 / 无痕模式 / 换浏览器配置**：本机数据会归零，且无法找回；清理前一定先导出备份。
- 归零后不只是进度丢失，**365 天去重记录也会丢**：实测（v5 当前默认 g3 的 pending 池，2026-01 起 365 天；**不含尚未生效的 35140 道 v5 规格题**）第 201 天清空去重记录后，201~365 天题面重复率从 **0% 升到 32.9%**，固定静态/逻辑题会明显反复出现。同脚本在 v4 基线重跑为 15.0%，差异来自 P1 后的题池构成（逻辑/场景题占比上升），不是新内容的结论。这不是 bug，是纯前端无账号的架构限制，v5 不解决。
- 建议：每周导出一次；换设备、升级浏览器、清理缓存前各导出一次。
